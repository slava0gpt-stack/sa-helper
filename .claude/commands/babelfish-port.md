description: Портирование кода БД, который Babelfish не принимает (MERGE, XML-методы, FORMATMESSAGE)
---

## Использование

```
/babelfish-port <схема.процедура | путь к .sql | каталог>
```

## Примеры

```
/babelfish-port import.city
/babelfish-port ./migration/procs/import.performance.sql
/babelfish-port ./migration/procs/          # весь каталог, по процедуре за раз
```

## Что делает

Переписывает код базы, который Babelfish отказывается создавать, и **доказывает запуском**,
что поведение не изменилось.

Порядок работы:

1. Накатывает исходник на Babelfish и читает точный текст блокера
2. Находит рецепт в базе знаний по тексту ошибки
3. Применяет замену по шаблону
4. Накатывает порт и проверяет, что объект создан
5. **Сравнивает с оригиналом запуском** — удачный путь, повтор, ошибка
6. Записывает расхождения поведения, если они есть
7. Выносит вердикт

## Что нужно перед запуском

Поднятый стенд с двумя движками — эталонный MS SQL и Babelfish, с одинаковой схемой
и одинаковыми данными. Без эталона проверить порт нечем.

Готовый compose лежит в `skills/babelfish-porting/resources/bench-compose.yml`,
там же в шапке — как узнать коллацию и режим целевой базы и что выставить после подъёма.

## Вердикты

| Вердикт | Значение |
|---|---|
| `ПОРТИРОВАНО` | создаётся, три сценария совпали, тест сохранён |
| `ПОРТИРОВАНО С ОГОВОРКАМИ` | совпадает, но есть краевые расхождения — они перечислены |
| `НЕ ПОРТИРУЕТСЯ` | блокер без известного обхода |

## Чего команда не делает

Не переключает приложение на Babelfish, не трогает строки подключения, не переписывает
клиентский код. Только код внутри базы.

Не проверяет конкурентность, производительность и уровни изоляции — об этом предупреждает
в отчёте отдельно.

## Связанные

- `/babelfish-check` — проверка совместимости читающего пути через shadow-исполнение.
  Запускать **до** этой команды: сначала выясняем, что читающий путь совместим,
  потом чиним пишущий.

  Обе команды поставляются вместе. По отдельности каждая покрывает половину:
  `/babelfish-check` — читающий путь (у базы web это 83% нагрузки),
  `/babelfish-port` — пишущий (42–46% точек доступа к БД).
